# Acceptance

Every acceptance criterion of [`spec.md`](spec.md) section 5.1 and the named test that proves it. A test is named by its file and its title as it is written in the file; a title with `%s` is a table-driven test that runs once per row. A test in `scripts/check-acceptance.test.mjs` fails the lint chain when a file or a title below no longer exists, and the named tests were run on the commit that wrote this table.

What is not proved here, because it needs the Bymax Finance adapter, is listed at the end and belongs to the Finance phase (P11).
